# SimpleYTDownloader v1.0.1

More ways to personalise your downloads and get help when something goes wrong.

## New

- **Optional thumbnail downloads:** enable **Save video thumbnails** in Settings to save an image beside each newly queued MP4 or MP3. Thumbnails are off by default.
- **Six accent colours:** choose **Orange, Blue, Violet, Mint, Rose, or Gold**. Colours apply immediately and can be saved for your next launch.
- **Error dialogs with support codes:** download, settings, and manual update failures now include a readable error code, a copyable report, and a **Report on GitHub** button.
- **Prefilled GitHub issues:** reports include the app version, error code, error message, and a template for reproduction steps. Review and submit the issue in your browser.

## Improved

- Updated SimpleYTDownloader branding, colourful action buttons, theme previews, and clearer thumbnail status in the queue.
- Thumbnail failures keep successfully downloaded media and offer a reportable warning.
- Existing thumbnail files are preserved with numbered filenames when necessary.
- Settings from 1.0.0 continue to work, with Orange as the default accent and thumbnail saving disabled until enabled.

## Download

Upload **`SimpleYTDownloader-v1.0.1.zip`** from `dist` to the **`v1.0.1`** GitHub Release. The ZIP contains only `SimpleYTDownloader.exe` at its root.

The application runs without Python or development tools. FFmpeg/FFprobe and a supported JavaScript runtime remain separate media dependencies. Thumbnails are saved as separate JPEG, PNG, or WebP files, not embedded artwork. No GitHub issue is submitted automatically.
