# SimpleYTDownloader v1.0.2

More flexible update downloads and reliable release notes.

## Fixed

- **Flexible ZIP filenames:** future updates accept a single ZIP attached to the official GitHub Release, including names such as `1.0.3.zip`.
- **Release descriptions stay visible:** release name, version, and notes are retained even if the ZIP is missing or invalid. Close the error report popup to view the release details.
- **Clear handling of multiple ZIPs:** the standard `SimpleYTDownloader-vX.Y.Z.zip` is preferred when present; otherwise an ambiguous release shows an error instead of choosing an arbitrary archive.

## Download checks

Updates still come only from published stable releases in EpicGamer1599/SimpleYTDownloader. Repository URLs, GitHub SHA-256 digests, ZIP contents, and the executable are validated before installation. Download links in release descriptions and GitHub's generated source archives are not application update assets.

## Publisher instructions

Upload **`dist/SimpleYTDownloader-v1.0.2.zip`** to the **`v1.0.2`** (or `1.0.2`) GitHub Release. This name is necessary for installed 1.0.0 and original 1.0.1 apps to receive the fix. After installing 1.0.2, users can receive future updates with shorter ZIP filenames too. Keep the standard filename if users may skip versions.

**`Builds/1.0.2.zip`** contains the same executable for manual installation. Each ZIP contains only `SimpleYTDownloader.exe` at its root. Existing settings, thumbnail downloads, accent themes, and issue reporting are retained.
