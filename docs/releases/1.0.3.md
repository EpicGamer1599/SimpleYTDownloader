# SimpleYTDownloader v1.0.3

A reliability update for downloads, preferences, and application updates.

## Fixed

- **Keep finished media when cancelling thumbnails:** MP4/MP3 files are saved before the optional thumbnail request. Cancelling that request keeps your video/audio and shows a warning for the unfinished thumbnail.
- **Recover from worker failures after saving:** a worker crash or error after its media-save notification no longer turns a successfully saved download into a failed item. The queue can continue.
- **Safer update completion:** after the replacement app acknowledges startup, a status-file or cleanup failure no longer causes an attempted rollback of the running app.
- **Reliable preference saves:** simultaneous app instances use independent temporary files. Failed writes preserve existing preferences, and oversized or deeply malformed settings recover to defaults.
- **Complete release-note scrolling:** longer descriptions can be scrolled to their final line; short notes cannot be scrolled into empty space.
- **Smoother long-text rendering:** long titles and URLs use fewer font measurements, and off-screen wrapped lines are skipped during rendering.
- **Better network cancellation:** GitHub responses are processed in available chunks, release checks have an overall deadline, and interrupted HTTP responses are reported cleanly and closed.
- **Safer temporary-file cleanup:** update downloads do not delete pre-existing partial files they did not create, and download cleanup warnings preserve earlier warning details.

## Download

Upload **`dist/SimpleYTDownloader-v1.0.3.zip`** to the **`v1.0.3`** (or `1.0.3`) GitHub Release. This filename supports users upgrading directly from 1.0.0 or the original 1.0.1. Versions 1.0.2 and newer also accept a single attached ZIP with a short filename.

**`Builds/1.0.3.zip`** contains the same EXE for manual installation. Each ZIP contains only `SimpleYTDownloader.exe` at its root. Existing themes, thumbnail preferences, error reporting, and download features are retained.

## Notes

No production GitHub update is performed by the tests. The update helper is copied from the currently installed EXE, so the helper fix applies to updates initiated from 1.0.3 onward. If Windows blocks status writes or cleanup after startup, recovery files may remain. Power-loss recovery, antivirus-specific locks, and future YouTube changes cannot be guaranteed. FFmpeg/FFprobe and a supported JavaScript runtime remain separate media dependencies.
