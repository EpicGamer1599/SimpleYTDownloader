# SimpleYTDownloader v1.0.4

Sound effects for your downloads, with a mute switch and more reliability fixes.

## New

- **Setting sounds:** an on/off click plays when you change any toggle preference.
- **Download activity sound:** a quiet loop plays while a queue item downloads, converts, or saves its thumbnail. It also plays during an application update download.
- **Completion chime:** hear when your media has finished saving, including a successful download with a thumbnail warning.
- **One sound switch:** turn **Settings → Sound Effects → Play interface and download sounds** on or off. Sounds are enabled by default; your choice is saved when **Remember settings** is enabled. Muting gives one last click, then stays silent.
- **Sounds inside the EXE:** the supplied `on_off.mp3`, `FinishDownload.mp3`, and `Downloading.wav` are embedded. No separate sound folder is needed.

## Fixed

- Invalid download progress, speed, ETA, and text values are handled before reaching the GUI, preventing malformed worker updates from crashing rendering.
- Opening or closing an error/update dialog immediately clears old button targets, preventing rapid clicks from reaching controls left over from the previous screen.
- Completion notifications are queued, so downloads that finish between GUI frames still trigger their chime once per completed attempt.

## Sound behaviour

The loop stops when work ends, cancellation is requested, sounds are muted, or the app closes. **Pause queue** still lets the current item finish, so its sound continues while it works. Setting clicks, the loop, and completion chimes use separate playback channels; the loop becomes quieter while a completion chime plays.

Missing or unsupported clips and unavailable audio devices leave the app usable. Settings shows the audio problem; switch sounds off and back on after reconnecting an unavailable device to retry initialization. Failed or cancelled attempts without saved media do not play the completion chime.

## Download

Upload **`dist/SimpleYTDownloader-v1.0.4.zip`** to the **`v1.0.4`** (or `1.0.4`) GitHub Release. This standard filename supports users upgrading directly from 1.0.0 and the original 1.0.1. Versions 1.0.2 and newer also accept a single attached ZIP with a short filename.

**`Builds/1.0.4.zip`** is the same package for manual installation. Each ZIP contains only `SimpleYTDownloader.exe` at its root, with the sounds embedded. Previous builds remain available.

## Notes

Existing themes, thumbnails, settings, error reports, and updater features are retained. No dependencies were added or upgraded. FFmpeg/FFprobe and a supported JavaScript runtime remain separate media dependencies.

Automated sound tests use the actual clips and SDL's dummy audio device, including playback inside the standalone EXE. Audible output and volume on individual speakers/headphones need a manual listening check. Update tests use disposable local copies and do not publish or install a production GitHub release.
